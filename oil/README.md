Oil Bottle Classifier

A simple image classification project for identifying oil bottle brands from shelf images.

Built using:

PyTorch
ResNet18 Transfer Learning
Streamlit

Supports 3 classes:

parachute
saffola
other
Features
Converts YOLO annotations into cropped classification images
Trains a ResNet18 image classifier
CLI inference support
Streamlit web app for predictions
GPU support (CUDA / Apple MPS)
